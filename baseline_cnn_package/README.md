# 本地基线CNN训练代码包

这个包包含了本地基线CNN模型训练的所有必要代码。

## 包含文件:

1. `train_baseline_cnn_features.py` - 训练脚本主入口
2. `cnn_model.py` - CNN模型定义
3. `feature_dataset_loader.py` - 数据集加载器
4. `dataset_split_utils.py` - 数据集划分工具
5. `dataset_name_utils.py` - 数据集名称处理工具
6. `font_utils.py` - 字体工具

## 使用方法:

```bash
python train_baseline_cnn_features.py [参数]
```

详细参数请参考 `train_baseline_cnn_features.py` 中的argparse配置。
